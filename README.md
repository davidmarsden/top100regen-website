# Top 100 Regen website

Source and design history for the Top 100 Regen Micro.blog site.

- Canonical home: `https://regen.smtop100.blog/`
- Legacy domain: `https://top100regen.website/`
- Sister site: `https://smtop100.blog/`

This repository starts from the September 2026 Micro.blog export and tracks the Regen site separately while keeping it inside the wider Top 100 family.

## Design direction

Top 100 Regen should have its own identity while remaining recognisably part of the Top 100 family. The shared family colour is blue; Regen uses a distinct lime/green accent and the strapline **“Same DNA. New generation.”**

## Architecture

The Regen site remains the editorial/home base for the sister world. Shared structured functions belong to the wider Top 100 ecosystem:

`Top 100 · Stats & History · Tournaments · Awards · Voting · Regen`

`top100regen.website` should redirect to `regen.smtop100.blog` after the subdomain has been connected and verified.
