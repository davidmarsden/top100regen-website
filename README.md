# Top 100 Regen website

Source and design history for the Top 100 Regen Micro.blog site.

- Current site: `https://top100regen.website/`
- Planned canonical home: `https://regen.smtop100.blog/`
- Sister site: `https://smtop100.blog/`

This repository starts from the September 2026 Micro.blog export and tracks the Regen makeover separately from the wider Top 100 migration.

## Design direction

Top 100 Regen should have its own identity while remaining recognisably part of the Top 100 family. The shared family colour is blue; Regen uses a distinct lime/green accent and the strapline **“Same DNA. New generation.”**

## Architecture

The Regen site remains the editorial/home base for the sister world. Shared structured functions increasingly belong to the wider Top 100 ecosystem:

`Top 100 · Archive · Tournaments · Awards · Rules · Regen`
